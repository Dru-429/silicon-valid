# Silicon Valid

Silicon Valid turns a public GitHub repository into an AI-powered technical debate.

Paste a GitHub repository URL and the app analyzes the codebase, then generates a five-person panel discussion where each character reviews a different part of the project.

The panel looks at areas such as:

- Code quality
- Backend and APIs
- Frontend
- Security
- Architecture
- Scalability

The debate uses evidence from the repository and ends with a technical verdict and actionable feedback.

## How it works

```text
GitHub Repository
        ↓
Repository Analysis
        ↓
Technical Findings
        ↓
5-Person AI Debate
        ↓
Evidence + Verdict
        ↓
Parallel Fix Plan
```

Silicon Valid turns a normal code review into an interactive technical roast.
